# Frontend Assignment: Build a Weather App

## Overview

Build a **responsive Weather App** using **HTML, CSS, and vanilla JavaScript**.

The app should allow users to search for a city and view its current weather information using a weather API.

## Requirements

Your application should:

* [ ] Have a clean and responsive user interface.
* [ ] Allow users to search for a city.
* [ ] Fetch weather data from a public Weather API.
* [ ] Display:

  * City name
  * Temperature
  * Weather condition
  * Weather icon
  * Humidity
  * Wind speed
* [ ] Show a loading state while fetching data.
* [ ] Show a friendly error message when a city is not found or the request fails.
* [ ] Allow users to search for multiple cities.
* [ ] Work properly on both desktop and mobile screens.

## JavaScript Concepts to Practice

You should demonstrate your understanding of:

* Variables and data types
* Functions
* Arrays and objects
* DOM manipulation
* Events and event listeners
* `fetch()` and APIs
* `async/await`
* Conditional statements
* Error handling

## Bonus

For extra points, add:

* [ ] 5-day weather forecast
* [ ] Current location weather
* [ ] °C / °F temperature toggle
* [ ] Recent/search history
* [ ] Dynamic background based on weather condition

## Deliverables

Submit:

1. `index.html`
2. `style.css`
3. `script.js`
4. A `README.md` explaining how to run the project
5. GitHub repository link

**Important:** Your application must be functional. A screenshot or static UI without working API integration will not be accepted.

## Goal

By completing this assignment, you should be able to build a real-world frontend application that consumes an external API and dynamically updates the UI based on user input.
