## Submission Instructions

1. Navigate to the `week-2` folder.
2. Inside it, create a folder named `submissions` if it doesn't already exist.
3. Inside the `submissions` folder, create a new folder using your name in the format:

```text

```

**Example:**

```text

└── john-danlami/
```

4. Place all of your assignment files inside your personal folder.

# How to Submit Your Work

### Stage your changes

```bash
git add .
```

### Commit your work

```bash
git commit -m "Complete Week 2 assignment"
```

### Pull the latest changes from the `main` branch

```bash
git pull origin main
```

If Git asks you to resolve any merge conflicts, do so before continuing.

### Push your work to your own branch

Replace `firstname-lastname` with your branch name.

```bash
git push origin firstname-lastname
```

**Example:**

```bash
git push origin john-danlami
```

> **Do not push directly to the `main` branch.** Always push to your own branch, then create a Pull Request if requested.
